# Desktop GUI build — native window (pywebview) + local WSGI server (waitress).
# Pulls in the core deps and Flask too, so a single install covers a source run:
#   pip install -r requirements-gui.txt   &&   python3 gui.py
# (Deliberately does NOT depend on gunicorn — it can't install on Windows.)
#
# Runtime: Qt WebEngine is bundled in the pre-built binaries.
# For a source run you need a working Qt/PyQt6 environment
# (provided by pywebview[qt]). No extra system packages required
# on modern Windows or most current Linux distributions.
-r requirements.txt
Flask>=3.0,<4.0
pywebview[qt]>=5.0
waitress>=3.0
